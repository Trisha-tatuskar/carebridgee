# CareBridge — Social Support Platform

CareBridge connects Donors, Volunteers, and Support Centers (NGOs / Orphanages / Shelters).
It supports emergency reporting (no login needed), map listing of hospitals and centers,
volunteer assignment, donations tracking, and dashboards.

## Tech Stack

- Python 3.12
- Django 5.x
- Django REST Framework
- MySQL 8.x with PyMySQL
- HTML, CSS (peach theme), JS
